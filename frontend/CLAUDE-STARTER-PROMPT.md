# CLAUDE-STARTER-PROMPT.md

You are implementing the mobile UI for a DALLIMO, a course-based social running platform.

Before editing code, read:
- CLAUDE.md
- docs/ui/PRODUCT-UX.md
- docs/ui/REFERENCE-MATRIX.md
- docs/ui/DESIGN-SYSTEM.md
- docs/ui/SCREEN-SPECS.md
- docs/ui/INTERACTION-SPECS.md
- docs/ui/ACCESSIBILITY.md
- docs/ui/VISUAL-QA.md

Do not create a generic fitness dashboard.

The product identity is:
- discover a running course,
- understand the course,
- choose a play mode,
- run,
- receive a verified result,
- compare/share/rematch.

Start with the Design System Playground, then Explore Home.

For every screen:
1. state the screen's single user question,
2. map relevant reference patterns,
3. define primary/secondary information,
4. implement required states,
5. reuse semantic tokens/components,
6. test realistic Korean content,
7. visually verify iOS/Android screenshots,
8. fix issues before moving on.

Do not lock arbitrary brand colors or typography until the visual exploration task.
Do not copy any reference app screen one-to-one.
