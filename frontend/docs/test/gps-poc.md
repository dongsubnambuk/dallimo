# GPS PoC 테스트 (WBS 1)

명세 17.1장 PoC 01 · 53장 GPS-M-001~004 · 57장 "GPS PoC Report" 문서.
코드는 준비되어 있고, 아래 결과 칸은 아이폰 야외 테스트 뒤에 채운다.

## 1. 무엇을 확인하나

| 항목 | 기준 |
| --- | --- |
| 거리 · 경로 | 30분 달린 거리가 다른 러닝 앱(또는 알려진 코스 거리)과 얼마나 다른가 |
| 화면 잠금 | 화면을 끄고 달려도 point가 1초 간격으로 계속 쌓이는가 |
| 앱 강제 종료 | 다시 켜면 이어서 기록되는가, 꺼져 있던 동안은 어떻게 되는가 |
| GPS 튐 | 건물 · 다리 · 나무가 많은 곳에서 거리가 튀지 않는가 |
| 정지 · 신호 대기 | 멈춰 있는 동안 거리가 늘지 않는가 |
| 배터리 | 30분에 몇 % 쓰는가 |

## 2. 설치

야외 테스트는 노트북 없이 달려야 하므로 JS가 앱 안에 들어간 빌드를 쓴다. 개발 서버에 붙는 개발 빌드는 집에서 확인할 때만 쓴다.
`EXPO_PUBLIC_GPS_POC=1`로 만든 빌드에서는 마이 탭 맨 아래에 "GPS PoC 기록 보기 · 내보내기"가 보인다.

| 방법 | 명령 |
| --- | --- |
| Mac + Xcode (무료, 7일마다 다시 설치) | `cd frontend && EXPO_PUBLIC_GPS_POC=1 npx expo run:ios --device --configuration Release` |
| Apple Developer 계정 + EAS | `cd frontend && npx eas build --profile gps-poc --platform ios` → 설치 링크로 설치 |

처음 켜면 위치 권한을 묻는다. "앱을 사용하는 동안 허용"이면 된다. 화면을 꺼도 상단에 파란 위치 표시가 뜨며 기록이 이어진다.

## 3. 시나리오

| ID | 시나리오 | 방법 | 기대 | 결과 |
| --- | --- | --- | --- | --- |
| GPS-M-001 | 화면 잠금 | 달리기 시작 → 화면 끄고 10분 → 켜기 | 거리 · 경로 이어짐. PoC 기록의 평균 간격 1초 안팎 | |
| GPS-M-002 | 비행기 모드 20분 | 달리는 중 비행기 모드 → 20분 뒤 끄기 | 러닝 중 "오프라인이에요" 안내, 기록은 계속. 오프라인으로 끝내면 "기록은 휴대폰에 저장했어요". 연결되면 PoC 기록의 서버 동기화가 SYNCED로 바뀜 | |
| GPS-M-003 | 앱 재시작 | 달리는 중 앱 전환기에서 앱 종료 → 다시 켜기 | 로그인 뒤 바로 러닝 화면, "앱이 꺼지기 전 기록을 불러왔어요", GPS를 잡으면 이어서 기록. 꺼져 있던 시간은 달린 시간에서 빠짐 | |
| GPS-M-004 | GPS 튐 | 고층 건물 사이 · 다리 밑 | 튄 point는 "순간 이동"으로 거리에서 빠지고 원본은 남음 | |
| 17.1 | 30분 야외 러닝 | 평소 코스 | 거리 오차 | |
| 17.1 | 정지 · 신호 대기 | 신호등에서 1~2분 | 거리 늘지 않음. 현재 페이스 `--` | |
| 17.1 | 장시간 | 60분 이상 | 배터리 %, 앱 느려짐 없음 | |

테스트가 끝나면 마이 → GPS PoC 기록에서 러닝마다 **JSON 내보내기**로 파일을 보내 준다. 지도에서 경로를 보고 싶으면 GPX를 gpx.studio 같은 곳에 올린다.

## 4. 이 결과로 정할 값

모두 `entities/run/policy.ts` · `features/run/engine/locationFeed.ts`에 PoC 시작값으로 들어가 있다.

| 키 | 시작값 | 정하는 근거 |
| --- | --- | --- |
| gps.required_accuracy_m (10.5장) | 20m | 정확도 낮음 비율, 튄 구간과 정확도 관계 |
| GPS 상태 '양호' | 10m 이하 | 야외 평균 정확도 |
| 순간 이동 속도 | 12m/s | 튄 point 속도 분포 |
| 순간 이동 다시 잡기 | 3번 연속 | 첫 point가 튄 경우 |
| 현재 페이스 창 | 20초 | 화면 페이스가 흔들리는 정도 |
| GPS 샘플링 (20.2장) | 최고 정확도, 1초, 거리 필터 없음 | 배터리 · point 수 |
