# 외부 기록 가져오기 실기기 확인 (명세 122장)

Apple 건강에서 달리기를 읽는 코드는 `modules/dallimo-health`(Swift, HealthKit)에 있다.
웹과 Expo Go에서는 HealthKit을 쓸 수 없다. 그래서 개발 중에는 가짜 건강 앱으로 화면과 서버를 확인했다(결정 로그 47항).
아래는 아이폰 개발 빌드에서 확인할 순서다. 결과 칸은 확인한 뒤 채운다.

## 1. 준비

| 항목 | 방법 |
| --- | --- |
| 서버 | 노트북에서 `docker compose up -d` → `./gradlew bootRun`. 아이폰과 노트북이 같은 와이파이에 있어야 한다 |
| 개발 빌드 | `cd frontend && EXPO_PUBLIC_API_URL=http://{노트북 IP}:8080 npx expo run:ios --device` |
| HealthKit 권한 | `app.json`에 `com.apple.developer.healthkit` entitlement와 `NSHealthShareUsageDescription`이 들어 있다. Xcode에서 서명 팀을 고르면 HealthKit capability가 붙는다. 무료 개인 팀에서 서명이 막히면 Apple Developer 계정이 필요하다 |
| 네이티브 모듈 연결 확인 | `cd frontend && npx expo-modules-autolinking resolve --platform apple`에 `DallimoHealthModule`이 보이면 된다 |
| 달리기 기록 | Apple Watch 운동 앱으로 **실외 달리기**를 한 번 이상 기록한다. 다른 러닝 앱이 건강 앱에 저장한 달리기도 읽는다 |
| 코스 매칭을 보려면 | 달린 길과 같은 코스가 서버에 있어야 한다. 앱에서 그 길로 코스를 먼저 등록한다 |

## 2. 시나리오

| ID | 시나리오 | 방법 | 기대 | 결과 |
| --- | --- | --- | --- | --- |
| IMP-1 | 연결 | 설정 → 외부 기록 → Apple 건강 → 연결하기 | 건강 앱 권한 창에 운동 · 운동 경로 · 걷기+달리기 거리 읽기가 나온다. 허용하면 "연결됨" | |
| IMP-2 | 후보 | 연결 직후 | 최근 30일 달리기가 "새 러닝 기록 N개를 발견했어요"로 보인다. 줄마다 날짜 · 기기(Apple Watch) · 거리 · 시간 · 페이스 · 경로 모양. 실내 달리기는 "실내" | |
| IMP-3 | 가져오기 | 기록을 골라 "N개 가져오기" | 코스와 맞으면 "○○과 97% 일치 · 인증 확인 중" → 몇 초 뒤 "코스 기록 인증". 코스가 없으면 "러닝 기록으로 저장했어요" | |
| IMP-4 | 다시 열기 | 가져오기 화면을 다시 연다 | 가져온 기록은 후보에서 빠지고 "가져온 기록 N개" | |
| IMP-5 | 배지 | 마이 → 러닝 기록, 기록 상세 | "Apple Watch에서 가져옴" 배지. 코스 기록이면 순위에도 보인다 | |
| IMP-6 | 달리모 기록과 겹침 | 달리모로 달리면서 워치 운동 앱도 켜 두고 → 가져오기 | "이미 달리모로 기록한 러닝이에요". 기록이 두 개 생기지 않는다 | |
| IMP-7 | 권한 거절 | 건강 앱 → 공유 → 앱 → 달리모에서 읽기를 모두 끈다 → 가져오기 화면 | 후보가 없고 "건강 앱 → 공유 → 앱에서 달리모 권한을 확인해 주세요" 안내 (HealthKit은 읽기 거절을 앱에 알려 주지 않는다) | |
| IMP-8 | 오프라인 | 비행기 모드에서 가져오기 | "가져오지 못했어요 · 연결을 확인하고 다시 시도해 주세요" → 연결 뒤 "다시 시도" | |
| IMP-9 | 긴 기록 | 1시간 넘는 달리기 | 경로 point가 많아도 가져온다(2만 개까지). 걸린 시간을 적는다 | |

## 3. 확인 뒤 정할 값

| 키 | 지금 값 | 정하는 근거 |
| --- | --- | --- |
| 가져온 기록 따라 달린 비율 | 90% (`VerificationPolicy.IMPORTED`) | 워치 경로로 실제 코스를 달렸을 때 나오는 일치율 |
| point 간격 가운데 값 | 5초 이하 | 워치 경로의 실제 간격 (보통 1초 안팎으로 알려져 있다) |
| 달리모 기록과 겹침 | 짧은 쪽 시간의 50% | IMP-6에서 두 기록 시각 차이 |
| 후보 기간 | 30일, 50개 | 사용자가 한 번에 가져오는 양 |
