# Apple Watch 연결 실기기 확인 (WATCH-001~004)

휴대폰이 GPS로 기록하고 Apple Watch 달리모 앱은 보여 주기 · 조작 · 심박을 맡는다(결정 로그 48항).
웹에서는 가짜 워치로 메시지 · 조작 흐름을 확인했다. 아래는 아이폰 + Apple Watch에서 확인할 순서다. 결과 칸은 확인한 뒤 채운다.

## 1. 구성

| 위치 | 하는 일 |
| --- | --- |
| `targets/watch/` | watchOS 앱(SwiftUI). `@bacons/apple-targets`가 `npx expo prebuild` 때 Xcode 워치 타깃으로 만든다 |
| `modules/dallimo-watch/` | 휴대폰 로컬 Expo 모듈(WatchConnectivity · HealthKit `startWatchApp`) |
| `src/shared/watch/watchTransport.ts` | 앱 쪽 경계. 네이티브 모듈이 없으면(웹 개발) 가짜 워치 |
| `src/features/watch/` | 보낼 메시지(`watchMessages.ts`)와 연결 훅(`useWatchLink.ts`) |

## 2. 준비

| 항목 | 방법 |
| --- | --- |
| Xcode | 16 이상 (워치 타깃이 폴더 동기화 그룹을 쓴다), watchOS 10 이상 워치 |
| 번들 id | `com.dongseopseo.dallimo`, 워치는 `com.dongseopseo.dallimo.watchkitapp`(결정 로그 63항). 바꾸려면 `IOS_BUNDLE_ID`와 `app.json` appExtensions를 같이 |
| 서명 팀 | `APPLE_TEAM_ID`를 주거나 Xcode에서 휴대폰 · 워치 타깃 모두 팀을 고른다. HealthKit capability가 두 타깃에 붙는다 |
| 빌드 | `cd frontend && APPLE_TEAM_ID={팀 id} npx expo prebuild --platform ios --clean` → `npx expo run:ios --device` (휴대폰 앱에 워치 앱이 들어간다) |
| 워치 앱 설치 | 휴대폰 Watch 앱 › 사용 가능한 앱 › 달리모 설치. 설정 › Apple Watch에 "Apple Watch와 연결됐어요"가 보이면 된다 |
| 권한 | 처음 달릴 때 워치에서 심박 읽기 · 운동 쓰기 권한을 묻는다 |

## 3. 시나리오

| ID | 시나리오 | 방법 | 기대 | 결과 |
| --- | --- | --- | --- | --- |
| WATCH-1 | 시작하면 워치에 보임 | 워치 앱을 켜지 않은 채 휴대폰에서 자유 달리기 시작 | 카운트다운 동안 워치 앱이 켜져 3 · 2 · 1 · 출발(햅틱). 이어서 거리 · 시간 · 페이스 · 심박 | |
| WATCH-2 | 실시간 | 5분 달리기 | 워치 거리 · 시간이 휴대폰과 1초 안쪽으로 같다. 손목을 내렸다 올려도 달리모 화면 | |
| WATCH-3 | 워치 일시정지 · 계속 | 워치 왼쪽 페이지 › 일시정지 → 계속 달리기 | 휴대폰도 일시정지 · 기록 중으로 바뀐다. 두 기기 모두 햅틱 | |
| WATCH-4 | 워치 끝내기 | 워치 › 끝내기 → 확인 | 휴대폰이 기록을 저장하고 결과로 간다. 워치는 요약(거리 · 시간 · 페이스) | |
| WATCH-5 | 심박 | 달리는 동안 | 워치 심박, 휴대폰 위쪽에 ♥ 심박(5초마다). 워치를 벗으면 15초 뒤 휴대폰에서 사라진다 | |
| WATCH-6 | 1km 햅틱 · 경고 | 1km 넘기기, 코스에서 벗어나기 | 1km마다 워치 햅틱, 코스 이탈 · GPS 약함이면 경고 햅틱 + "코스 이탈 30m" | |
| WATCH-7 | 코스 · PB · 도전 | PB 어택으로 코스 달리기 | 워치 아래 한 줄 "목표 0:05 빨라요" · 코스 진행 %. 완주하면 "완주 기록 저장" 버튼(확인 없음) | |
| WATCH-8 | 인터벌 | 직접 넘기는 구간이 있는 인터벌 | 워치 "빠르게 2/5 · 3/12 · 120m 남음", 구간이 바뀔 때 햅틱, 직접 넘기는 구간이면 "다음 구간" | |
| WATCH-9 | 함께 달리기 | 레이스 참가 | 워치 "4명 중 2위 · 선두와 12초 차이", 워치 "그만두기" → 확인하면 중도 포기 | |
| WATCH-10 | 화면 끄고 | 휴대폰 화면을 끄고 주머니에 넣고 달리기 | 워치 값이 계속 바뀐다. 워치 조작이 휴대폰에 반영된다 | |
| WATCH-11 | 연결 끊김 | 달리는 중 휴대폰 블루투스 끄기 → 켜기 | 워치 "휴대폰 연결 끊김", 조작하면 "휴대폰과 연결이 끊겼어요". 다시 켜면 이어서 | |
| WATCH-12 | 건강 앱 | 끝낸 뒤 건강 앱 › 운동 | 달리모 운동이 하나 남는다(활동 링 반영). 외부 기록 가져오기 후보에는 나오지 않는다 | |
| WATCH-13 | 취소 | 카운트다운 중 취소 | 워치 앱이 대기 화면으로, 건강 앱에 운동이 남지 않는다 | |
| WATCH-14 | 설정 끄기 | 설정 › Apple Watch › 워치에 러닝 보여주기 끄기 | 달리기를 시작해도 워치 앱이 켜지지 않는다 | |

## 4. 확인 뒤 정할 값

| 값 | 지금 | 근거로 볼 것 |
| --- | --- | --- |
| 워치로 보내는 간격 | 1초 | 배터리 · 화면 끄고 달릴 때 전달 간격 |
| 휴대폰으로 보내는 심박 간격 | 5초 | 휴대폰 화면에 필요한 정도 |
| 심박을 지우는 시간 | 15초 | 워치를 벗거나 연결이 끊겼을 때 |
| 워치 운동 거리 | 워치가 잰 값(건강 앱 운동) | 달리모 기록(휴대폰 GPS)과 차이. 크면 워치 운동에서 거리를 빼는 방법을 본다 |
