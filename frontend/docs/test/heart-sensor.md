# 블루투스 심박 센서 실기기 확인

심박 벨트, 심박수 브로드캐스트를 켠 워치(샤오미 · 레드미 · 가민 등)에서 달리는 동안 심박을 받는다(결정 로그 80항).
웹에서는 가짜 센서로 찾기 · 연결 · 끊김 · 다시 연결 · 러닝 화면 심박을 확인했다. 아래는 아이폰 + 실제 센서에서 확인할 순서다. 결과 칸은 확인한 뒤 채운다.

## 1. 구성

| 위치 | 하는 일 |
| --- | --- |
| `modules/dallimo-heart/` | 휴대폰 로컬 Expo 모듈(CoreBluetooth). 표준 Heart Rate Service(0x180D)를 찾고 Heart Rate Measurement(0x2A37)를 받는다 |
| `plugins/with-heart-sensor.js` | `NSBluetoothAlwaysUsageDescription` 문구, `UIBackgroundModes`에 `bluetooth-central` 더하기 |
| `src/shared/heart/heartSensorTransport.ts` | 앱 쪽 경계. 네이티브 모듈이 없으면(웹 개발) 가짜 센서 |
| `src/features/heart-sensor/` | 설정 › 심박 센서 화면, 달리는 동안 연결하는 훅 |
| `src/features/run/heartRateLive.ts` | 워치 · 센서 심박을 합친다. 센서 값이 있으면 센서를 쓰고, 기록에는 약 5초에 하나 남긴다 |

## 2. 준비

| 항목 | 방법 |
| --- | --- |
| 빌드 | 네이티브 모듈이 새로 들어가서 새 개발 빌드 · 스토어 빌드가 필요하다. OTA로는 들어가지 않는다 |
| 레드미 워치 5 라이트 | 워치 설정에서 심박수 브로드캐스트(심박 공유)를 켠다. 이 기종이 지원하는지는 공식 자료로 확인하지 못했다. 메뉴가 없으면 센서로 쓸 수 없다 |
| 심박 벨트 | 착용하면 켜진다(Polar H10 · Garmin HRM 등) |
| 권한 | 설정 › 심박 센서를 처음 열 때 iOS가 블루투스 권한을 묻는다 |

## 3. 시나리오

| ID | 시나리오 | 방법 | 기대 | 결과 |
| --- | --- | --- | --- | --- |
| HRS-1 | 찾기 | 설정 › 심박 › 심박 센서 | 블루투스 권한을 묻고, 허용하면 15초 동안 주변 센서를 찾는다. 기기 이름과 거리(가까이 · 조금 떨어져 · 멀리) | |
| HRS-2 | 연결 | 목록에서 센서 누르기 | "연결한 센서"에 저장되고 몇 초 안에 "연결됨"과 심박(bpm)이 1초마다 바뀐다 | |
| HRS-3 | 달리기 | 센서를 저장한 채 자유 달리기 시작 | 카운트다운 동안 연결되고, 러닝 화면 위쪽 ♥에 센서 심박 | |
| HRS-4 | 화면 끄고 | 휴대폰 화면을 끄고 주머니에 넣고 5분 달리기 | 끝낸 뒤 결과에 평균 · 최고 심박(심박 저장 동의를 켠 경우). 기록 중간이 비지 않는다 | |
| HRS-5 | 끊김 · 다시 연결 | 달리는 중 센서를 벗거나 끄기 → 다시 켜기 | 15초 뒤 ♥가 사라지고, 다시 켜면 저절로 연결돼 ♥가 돌아온다. 거리 · 시간 기록은 그대로 | |
| HRS-6 | 끝내면 끊기 | 러닝을 끝내고 결과 화면으로 | 센서 연결이 끊긴다(센서 앱 · 워치에서 연결 표시가 사라짐) | |
| HRS-7 | Apple Watch와 같이 | Apple Watch 달리모 앱과 센서를 함께 쓰기 | 휴대폰 ♥는 센서 값. 센서가 끊기면 15초 뒤부터 워치 값 | |
| HRS-8 | 블루투스 꺼짐 | 제어 센터에서 블루투스 끄고 심박 센서 화면 | "블루투스가 꺼져 있어요" | |
| HRS-9 | 권한 거부 | 설정 › 달리모 › 블루투스 끄고 심박 센서 화면 | "블루투스 권한이 없어요" + 휴대폰 설정 열기 | |
| HRS-10 | 연결 해제 | 이 센서 연결 해제 | 저장이 지워지고 다음 달리기부터 연결하지 않는다 | |

## 4. 확인 뒤 정할 값

| 값 | 지금 | 근거로 볼 것 |
| --- | --- | --- |
| 찾는 시간 | 15초 | 센서가 목록에 뜨는 데 걸리는 시간 |
| 기록 간격 | 약 5초(4초 이상 간격) | 워치 심박과 같은 간격. 서버 최대 3600개 |
| 심박을 지우는 시간 | 15초 | 센서를 벗거나 연결이 끊겼을 때 |
