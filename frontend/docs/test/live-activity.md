# 잠금 화면 · 다이내믹 아일랜드 · 워치 참가자 실기기 확인

달리는 동안 잠금 화면과 다이내믹 아일랜드에 러닝을 보여 주고, 함께 달리기면 친구 진행 상황을 함께 보여 준다(결정 로그 83항).
워치에는 함께 달리기 중 참가자 페이지가 생긴다. 웹에서는 보내는 데이터(globalThis.__dallimoLiveActivity · __dallimoWatch)만 확인했다. 결과 칸은 확인한 뒤 채운다.

## 1. 구성

| 위치 | 하는 일 |
| --- | --- |
| `targets/live-activity/` | 위젯 확장(라이브 액티비티). 잠금 화면 · 다이내믹 아일랜드 화면 (SwiftUI) |
| `modules/dallimo-live-activity/` | 휴대폰 로컬 Expo 모듈. 시작 · 갱신 · 끝내기 (ActivityKit) |
| `DallimoRunAttributes.swift` | 위 두 곳에 같은 정의가 있다. 함께 바꾼다 |
| `src/features/run/liveActivity/useRunLiveActivity.ts` | 러닝 화면 · 함께 달리기 화면이 1초마다 · 상태가 바뀔 때 보낸다 |
| `src/features/together/live/liveRank.ts` `watchPeople` | 참가자 진행 상황 (순위 순, 목표 거리 대비 진행률, 위치 없음) |

## 2. 준비

| 항목 | 방법 |
| --- | --- |
| 빌드 | 위젯 확장 · 네이티브 모듈이 새로 들어가서 새 빌드가 필요하다. EAS가 `com.dongseopseo.dallimo.liveactivity` App ID · 프로필을 만든다 (`app.json` appExtensions) |
| 기기 | iOS 16.2 이상. 다이내믹 아일랜드는 iPhone 14 Pro 이상 |
| 설정 | 휴대폰 설정 › 달리모 › 실시간 현황 켜짐, 달리모 설정 › 러닝 › 잠금 화면에 러닝 보여주기 켜짐 |

## 3. 시나리오

| ID | 시나리오 | 방법 | 기대 | 결과 |
| --- | --- | --- | --- | --- |
| LA-1 | 잠금 화면 | 자유 달리기 시작 → 화면 잠그기 | 잠금 화면에 "달리모 · 자유 달리기 · 기록 중", 거리 · 페이스 · 현재 페이스가 1초마다 바뀌고 시간이 초마다 흐른다 | |
| LA-1b | 모든 러닝 | 코스 · PB · 도전 · 인터벌 · 이어 달리기 각각 | 모두 잠금 화면 · 다이내믹 아일랜드에 뜬다 | |
| LA-2 | 다이내믹 아일랜드 | 달리는 중 홈으로 나가기 | 왼쪽 거리(민트, 1초마다), 오른쪽 시간(초마다). 길게 누르면 거리 · 시간 · 페이스 · 한 줄 | |
| LA-3 | 일시정지 | 일시정지 → 잠금 화면 | "일시정지", 시간이 멈춘다. 다이내믹 아일랜드 최소 모양은 일시정지 아이콘 | |
| LA-4 | 코스 · PB | PB 어택 시작 → 잠금 화면 | 아래 줄 "목표 0:05 빨라요"처럼 목표 차이 | |
| LA-5 | 함께 달리기 | 레이스 참가 → 잠금 화면 | 참가자 4명까지 순위 · 이름 · 진행 막대 · 거리, 나는 민트. 다이내믹 아일랜드 오른쪽은 "2위" | |
| LA-6 | 끝내기 | 러닝을 저장하고 끝내기 | "기록 저장" 요약이 5분 남았다가 사라진다 | |
| LA-7 | 기록 없이 끝내기 | 짧게 달리고 "기록하지 않고 끝내기" | 바로 사라진다 | |
| LA-8 | 설정 끄기 | 잠금 화면에 러닝 보여주기 끄고 달리기 | 라이브 액티비티가 뜨지 않는다 | |
| LA-9 | 앱이 꺼짐 | 달리는 중 앱을 강제로 끄고 다시 열기 | 이어 달리기면 새로 뜨고, 이어 달릴 러닝이 없으면 남은 것이 지워진다 | |
| W-1 | 워치 참가자 | 함께 달리기 중 워치에서 오른쪽으로 넘기기 | "참가자" 페이지: 순위 · 이름 · 거리 · 진행 막대, 나는 민트. 혼자 달리면 페이지가 없다 | |
