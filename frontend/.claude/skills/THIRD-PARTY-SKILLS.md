# Third-party Claude Code skills

`frontend/.claude/skills/`에 project-local로 설치한 외부 스킬의 출처, 설치 커밋, 라이선스 고지입니다.
스펙 107장에 따라 고정 커밋에서 복사했습니다. 업데이트할 때는 SKILL.md diff를 검토한 뒤 이 표의 커밋을 갱신합니다.

| 저장소 | 설치 커밋 | 설치한 스킬 | 라이선스 |
| --- | --- | --- | --- |
| [draftbit/mobile-taste-skill](https://github.com/draftbit/mobile-taste-skill) | `eb58d9896d446b574ba4b0fb83e3587e8708a9e1` | mobile-taste, mobile-nav-plan, mobile-design-system, mobile-design-review, mobile-redesign-screen, mobile-redesign-app, _shared | MIT |
| [richhemsley3/claude-design-skills](https://github.com/richhemsley3/claude-design-skills) | `1185d0d84974eaed6e927b953243c96754de02b6` | skills/ 전체 18개 | MIT |
| [dawitlabs/ui-skills](https://github.com/dawitlabs/ui-skills) | `6973cc6df7772780d31a4891fb60859f53f3e0b2` | ui-init, design-grill, uiux, uicolor, animate, copy, a11y, tokens, ui-design-principles | MIT |
| [charlomrt-boop/ui-design-skill](https://github.com/charlomrt-boop/ui-design-skill) | `21587b1d511bc7baaf4c1b8b0248968b8c556015` | ui-design | MIT |
| [szilu/ux-designer-skill](https://github.com/szilu/ux-designer-skill) | `3f058996e2a85d6545faaa63040d263d32e632c9` | ux-designer | MIT |
